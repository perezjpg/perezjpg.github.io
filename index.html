01 // Projects

FEATURED · PRIVATE REPO

mc-panel

A control panel I host myself for a Minecraft (Fabric) server. One web page to start, stop, update, back up and tune the server. It is built with FastAPI and vanilla JavaScript, and runs in Docker on my own PC so friends can jump in any time.

  • Python
  • FastAPI
  • Docker
  • SQLite
  • pytest

WHAT IT DOES

  • ▸ Switch Minecraft version and mod loader
  • ▸ Install modpacks from Modrinth and CurseForge
  • ▸ Backups, restore and a worlds manager
  • ▸ Live CPU and RAM limits
  • ▸ Pauses itself when nobody is online
  • ▸ Crash detection and an activity log
  • ▸ A page for inviting friends, with a public tunnel

04 // About

Right now I'm working through a C++ course one lab at a time, while keeping my own projects running at home on Docker. I like software that is tested, runs on my own hardware, and stays out of the way.

AI coding tools are part of how I work, and I try to use them well: I plan the project, direct the build, test everything on real hardware and keep every change in version control. That lets me ship complete, tested projects far faster than I could alone.
