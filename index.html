FEATURED · PRIVATE REPO

mc-panel

A self-hosted control panel for a Minecraft (Fabric) server. One web page to start, stop, update, back up and tune the server — built with FastAPI and vanilla JavaScript, running in Docker on my own PC so friends can jump in any time.

  • Python
  • FastAPI
  • Docker
  • SQLite
  • pytest

WHAT IT DOES

  • ▸ Switch Minecraft version and mod loader
  • ▸ Install modpacks from Modrinth and CurseForge
  • ▸ Backups, restore and a worlds manager
  • ▸ Live CPU and RAM limits
  • ▸ Auto-pause when nobody is online
  • ▸ Crash detection and an activity log
  • ▸ Invite-friends page with a public tunnel
